## Personal Portfolio Website

### Overview 

This repository contains the source code for my personal portfolio website, designed and built using HTML5, CSS3, and JavaScript.

The website serves as an interactive platform to showcase my technical skills, academic journey, projects, and personal achievements. It features a clean, modern design with smooth animations and full responsiveness across desktop, tablet, and mobile devices.

### Key Features 

**Hero Section:** A clean and welcoming introduction area presenting essential personal highlights.

**About Me:** A short overview highlighting my background, career goals, and academic journey.

**Skills Overview:** A visually structured display of both technical and soft skills.

**Projects Showcase:** A curated selection of key projects featuring descriptive overviews, tech stack tags, and links to source code and live demos.

**Education & Experience Timeline:** A chronological overview of academic background and relevant experience.

**Contact Form:** A functional and straightforward form for direct communication and networking inquiries.

**Responsive Design:** Optimized layout with smooth animations to deliver a seamless user experience across all screen sizes.

### Built With

HTML5 - Structure and semantic content

CSS3 - Styling, responsive layouts (Flexbox/Grid), and animations

JavaScript - Interactivity and smooth navigation
